Connect Google Gmail API

One-time setup for your own Google Cloud project. This starter uses Google OAuth in the browser and Gmail read-only access; it does not use email/password login.

  1. Open Google Cloud Console and create/select a project.
  2. Enable Gmail API in APIs & Services → Library.
  3. Configure OAuth consent screen. While in testing, add your Google accounts as test users if required.
  4. Create an OAuth Client ID of type Web application. Add this page's origin to Authorized JavaScript origins. For a local file, OAuth may reject the origin; serve the file from localhost instead.
  5. Paste the Client ID below. This value is public by design; never paste a client secret here.

Important: Google may require verification or impose OAuth/testing limits for a large number of accounts. 100+ accounts may not be practical in a browser-only app. Never enter Gmail passwords into a third-party dashboard.
